# conv

Renders raw `conv-<id>` strings (e.g. `conv-1777406728-mb12`) inline as
clickable chips. Agents write the bare id in their text — no tag wrapping
needed — and the active-data linkify primitive replaces matches at render
time.

Clicking calls `openPane(conversationPane, { convId })` — opens the
referenced conversation in whichever pane layout the host uses. The chip
resolves the title and current status via `useConversationById` (the
`conversations.by-id` read, which finds any conversation however old); falls
back to the raw id while that read loads or when no conversation has the id.

The id pattern matches conversation ids generated by
`plugins/conversations/server/internal/lifecycle.ts`
(`conv-<unix-seconds>-<4 base36 chars>`).
