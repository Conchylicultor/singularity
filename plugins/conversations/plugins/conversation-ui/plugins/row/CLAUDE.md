# row

`<ConversationRow conv={…}/>` — a conversation, as a full-width list line that
opens its run beside the surface listing it.

The `item` plugin states its contract as "pure presentation — no click handler,
no router awareness, no chrome; surfaces wrap their own button/link around it".
`chip` is that wrapper for the pill case; **this is it for the row case**. Four
surfaces built it by hand — task detail's attempts, the launched-attempts card
in a transcript, an agent-note card's authors, a TODO card's latest run — and
none of them agreed on what "the open one" meant or on whether a second click
closed the column.

What it wraps `ConversationItem` in:

- a `Row` whose `selected` is whether this conversation is the column **this
  surface** opened — `useConversationOpener()`, which reads
  `conversationPane.useOpenedHere()`.
- a click that opens that column, and closes it again when it is already open.
- a `title` of `"Starting…"` while the conversation has no title yet
  (`conversationTitle`, shared with the visible label `item` paints).

## The knobs, and why they are these

- **`layout`** — `"block"` (default, the full list line) or `"inline"` (the
  compact one a popover uses). ONE word, because it drives both the
  `ConversationItem` layout and the `Row`'s `size`/`hover`, which callers used
  to keep in step by hand.
- **`trailing`** — presentational content after the body (the authorship row's
  "when this conversation first wrote here").
- **`actions`** — `Row`'s interactive slot (task detail's "Open as page", which
  calls `openAsPage` off the same opener). Never put a control in `trailing`:
  `Row`'s contract is that a clickable row's body is presentational.
- **`onOpen`** — fired after navigating, so a popover can dismiss itself.

## `ConversationRowById`

For a surface holding only an id. It resolves the id and, while it is
unresolved — still loading, or a conversation that outlived the record naming
it — renders the muted id, still clickable. Those two cases are
indistinguishable from the client, so the row claims neither.

## Not a DataView

These are transient chrome: a handful of runs inside a card or a popover, with
no search / sort / filter / grouping to earn. A homogeneous set of domain
records with a surface of its own is a `data-view` — see
`plugins/primitives/plugins/data-view/CLAUDE.md`.
