# conversation-ui

Umbrella for visual primitives that render a `Conversation` in the UI. Each
sub-plugin under `plugins/` ships one visual building block (cards, mentions,
breadcrumbs in the future). Surfaces import the specific primitive they need
directly — the umbrella does not re-export.

Today there are two, and the split between them is the point:

- **`item`** paints a conversation and nothing else — no click handler, no
  router awareness, no chrome — so a row, a chip and a card can each wrap their
  own around one rendering.
- **`chip`** is one of those wrappers, written once: a clickable chip that opens
  the run. Every surface showing a conversation as a pill uses it, rather than
  hand-rolling the same pill again.

## Plugin reference

- Description: Umbrella for visual primitives that render a Conversation. Sub-plugins ship the actual components (item rows/chips, future cards/mentions/etc.).
- Sub-plugins:
  - **`chip`** — A conversation as a clickable chip that opens its run: a ghost ToggleChip around an inline ConversationItem, active while that run is the open column.
  - **`item`** — Visual primitive for rendering a Conversation as a row or inline chip. Used by every surface that lists conversations.
