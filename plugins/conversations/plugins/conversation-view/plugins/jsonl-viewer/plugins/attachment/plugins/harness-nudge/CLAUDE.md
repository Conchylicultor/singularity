# harness-nudge

`batching_reminder_sent` and `silent_turn_reminder` are the same fact: the
harness slipped the agent a one-line coaching note mid-session — *batch the tool
calls that don't depend on each other*, *say something so the user knows you're
alive*. One plugin, one component, because a reader cares about the same thing
in both cases and the two should not drift into two different-looking rows.

The row is an `EventLine`. A nudge is not the agent's turn and not the user's,
and it is never the point of the conversation — it is the machinery talking to
itself. The label names *which* nudge (`Batching reminder`, `Check-in
reminder`), and the note's own text follows, truncated to one line.

Truncating hides nothing: the row's raw-JSON action carries the full text, and
these notes are near-identical every time they fire. The batching reminder alone
appears dozens of times in a long session, so a row that spent three lines on it
would push the actual work off the screen.

`model` is not rendered — which model was being coached is plumbing, not
something a reader takes away from the row.
