# remote-session

The harness emits `remote_session_change` when the conversation starts being
followed from claude.ai. The payload is mostly instructions aimed at the agent:
the exact `Co-Authored-By` / `Claude-Session` trailer to put on commits from
here on, the footer to put on pull requests, and a flag saying files can now be
handed to the user remotely.

None of that is what a reader wants from the row. The fact worth reading is
*this session is now mirrored to claude.ai, and here it is* — one line, so an
`EventLine` and not a card. A card whose body only restated the boilerplate
would be noise, and the boilerplate is one raw-JSON click away for anyone
chasing an attribution question.

The link text is the session id (`session_01Dry…`), not the whole URL: the id is
the part that distinguishes one session from another, and the `https://claude.ai/code/`
prefix repeats on every such row. The row throws when the payload carries no
`url` — a "remote session" line that links nowhere would be a claim the reader
cannot check.
