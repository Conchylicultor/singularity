# date

The harness stamps the agent's calendar date into the transcript in two
spellings, and this plugin owns both: the current `date` attachment
(`{ date, changed? }`, Claude Code ≥ 2.1.260) and the legacy `date_change`
one (`{ newDate }`), which older transcripts still carry and which is
exactly the `changed: true` case of the new spelling. One plugin renders
them so a midnight crossing cannot look like two different events
depending on which harness version wrote the log.

Two facts, one grammar:

- **the stamp** (`changed` absent) — routine, once per session/turn. Fully
  muted `EventLine`, no card: the reader glances past it.
- **the crossing** (`changed: true`, or any `date_change`) — the
  conversation ran past midnight. Same one-line grammar, but the label says
  so and the date is the row's one emphasized value.

The value the row adds over the raw payload is the weekday: `2026-09-08`
becomes `Tuesday, September 8, 2026`, which is what orients a reader
scrolling a long transcript. There is nothing to expand, so there is no
card — a `CollapsibleCard` whose body only restates its label is noise.
