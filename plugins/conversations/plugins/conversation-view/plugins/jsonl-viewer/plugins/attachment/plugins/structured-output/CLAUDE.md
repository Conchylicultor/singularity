# structured-output

The result a subagent returned against a schema it was asked to fill.

`data` is an **arbitrary object** — every payload in the sample has a different
key set (`summary/facts/constraints/openQuestions`, `title/thesis/design/steps`,
`scores/winner/graft/fatalFlaws`, …), because each one answers a different
schema. There is no shape to hardcode, so the row reads whatever it is handed.

## The collapsed line

```
Structured output  · 6 fields   Summary — The repo has exactly 102 production `defineRoute` call sites…
```

The field count says how much is in there; the headline says what it is about.
Finding that headline is the only clever part:

- `title` is the obvious answer, but **only two payloads in five carry one**.
- The general rule is the schema author's own ordering — the FIRST declared
  field holding a string is the one they put first, and its first line is the
  headline. That picks `summary` for the research schemas, `title` for the design
  ones, `winner` for the bake-off one.
- The key is named alongside the text (`Summary — …`, `Winner — harness`) unless
  it is `title`, where the name adds nothing. Without that prefix a headline
  taken from some other field would read as if the result had titled itself.

The headline is passed as the card's `summary`, **not** its `note`. `note` sits
in the header's rigid identity zone, where a sentence-long title refuses to
shrink and blows the row open; `summary` is the header's one flexible cell, so
it ellipsizes when the pane is narrow.

`toolUseID` is never rendered: it identifies the tool call, not the result, and
this row already sits beside that call.

## The body is one level deep, on purpose

Each key becomes a humanised muted heading (`openQuestions` → `Open questions`)
with its value below: a string as pre-wrapped prose, a list of strings as
bulleted lines, anything else as indented JSON. No recursive tree viewer — these
fields are *prose*, and a JSON tree would render an argument as a shape. The
rare nested value (a `facts: [{fact, citation, relevance}]` list) falls back to
JSON, which is honest about being structure.

Collapsed by default, capped at `max-h-96`: some of these results run to
thousands of words.
