# instructions

The project instruction files (CLAUDE.md) loaded at launch.

**Deliberately the twin of `nested-memory`.** That sibling renders the same
idea for ONE file picked up mid-session; this is the plural, opening-of-the-
session form. Same card, same `FilePath`, same capped pre-wrapped body — keep
them looking alike, so the reader sees one family instead of two unrelated rows.

**A card, collapsed.** The content is long and standing context; the collapsed
line answers "which files, how many" and the body waits. With exactly one file
the path moves to the `aside` (it identifies the row) and the body drops it, so
the card never restates its own header.
