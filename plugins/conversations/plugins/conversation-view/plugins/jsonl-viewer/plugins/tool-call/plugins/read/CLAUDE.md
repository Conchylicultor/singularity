# read

Renderer for `Read` tool calls in the JSONL viewer.

Collapsed by default (Read is high-volume). Summary line: clickable filename chip + optional `L42–84` line range badge.

Expanded: syntax-highlighted code block with line numbers derived from the `cat -n` output format. For image files (png, jpg, gif, webp, svg, ico, bmp, avif), the card opens by default and shows the image fetched from `/api/code/:worktree/image` as a `ViewerThumbnail` (`primitives/overlay/image-viewer`): capped inline, and a click opens the full-window viewer, stepping through the transcript's other images. Error results surface as red text; success is silent.
