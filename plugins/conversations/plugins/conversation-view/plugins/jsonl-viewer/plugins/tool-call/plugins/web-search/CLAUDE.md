# web-search

Renderer for `WebSearch` tool calls in the JSONL viewer.

The result is text, parsed by `readWebSearch` (`web/internal/web-search.ts`):
a `Web search results for query:` header, one `Links: [...]` JSON line per
search round (an `extended` search runs several, repeating URLs — deduplicated
here), the model-written summary, and a trailing `REMINDER:` to the model
(stripped).

- Collapsed: the query, with `· extended`, a domain scope (`allowed_domains` /
  `blocked_domains`) and the source count as the note.
- Opened: the scope, the summary as markdown in full, then `Sources · N from M
  sites` folded by default — links grouped by host (`www.` dropped), busiest
  site first.
- A failed call (e.g. permission denied) shows the error text.
