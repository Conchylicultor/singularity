# task-notification

The `<task-notification>` row: a background task ended (a sub-agent, a
background shell, …), with its status, summary and output path.

## The row names no kind of task

What the row opens is contributed through `TaskNotification.Open`: each
contribution's `useClaim(event, conversationId)` answers `pending`, `declined`
or `claimed{ target: { label, icon, open } }`. The row asks them in
registration order and draws the FIRST claim's button, or none when nobody
claims it. A contributor still `pending` holds the chain — a later one must not
claim what may be its task, and the wrong pane is worse than a late button.

Each contributor claims by joining the notification against its own live read:
`tool-call/agent` against the conversation's sub-agents (opening the report
pane by the sub-agent's own id), `background-shells` against its shells
(task id = shell id; opening the output pane). The row never imports either.
