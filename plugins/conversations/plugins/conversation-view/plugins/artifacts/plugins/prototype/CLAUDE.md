# prototype

The prototypes a conversation designed, changed or merely named — one of the
kinds in the conversation's Artifacts popover.

## What counts as a sighting

The id's shape, the word guard around it and the walk over a tool input's
string leaves are **not here**: they are `prototypeIdsIn`, which lives beside
the mint it has to agree with (`apps/prototypes/plugins/files/core`) and is
shared with the end-of-turn checkpoint job. This plugin adds only the reading —
which part of an event to scan, and what the scan means.

| The event | The relation |
| --- | --- |
| a `Bash` command running `prototype new`, once it returned an id | **created** |
| a `Write`/`Edit` whose `file_path` is inside the prototype's folder | **edited** |
| any other mention — a `Read`, a Bash line, an `Agent` prompt, a bare id in the agent's or the user's words | **referenced** |

The mint is the one place the **result** is read rather than the input: the
command prints the id it made, and the caller never writes it, so the result is
the only place a created id exists. Every other relation is decided from the
input alone.

Each id is judged on its own within one call, which is why the rules compose:
a `Write` into one prototype whose content quotes another's id edited the first
and only referenced the second.

## Titles

`prototypesResource` is a live, app-wide list re-broadcast on every file change
under the prototypes dir, so a popover full of ids costs no requests and the
titles follow a rename of the `<title>` live.

Two states are not a title and do not pretend to be one:

- **not loaded yet** — skeleton rows, one per artifact. The *count* is known from
  the transcript alone, but a title is not, and the opaque id standing in for one
  would read as the answer rather than as the wait for it.
- **no such prototype** — the id is opaque and permanent, so an unresolved one is
  not a stale label: the folder is gone, or was never on this machine. The row
  shows the id, greyed and inert, and says so in its tooltip instead of opening
  an empty pane.
