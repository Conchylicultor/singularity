# research

The design docs a conversation produced, in the Artifacts popover.

## What counts as one

The `plan` skill files every design doc at `research/YYYY-MM-DD-<category>-<name>.md`,
or `sidequests/<quest>/research/YYYY-MM-DD-<name>.md` for a sidequest. So the
extractor looks for exactly those two shapes at the end of a `Read` / `Write` /
`Edit` / `MultiEdit` path — as a suffix, because the tool call carries an
absolute path — and keeps the repo-relative tail as the artifact's key.

`Write` made the doc, `Edit` (and `MultiEdit`, which is an edit with several
replacements) changed it, `Read` only looked at it.

## The title drops the date and the category

`2026-09-19-conversations-artifacts-popover.md` shows as "Artifacts popover".
The date is filing, and inside one conversation's popover nearly every doc
carries the same category, so it says nothing while taking half the row. The
whole path stays in the row's tooltip.

The category is simply the first dash-separated word, because nothing in the
file name marks where it ends — so a doc named after a two-word area
(`…-data-view-adoption.md`) loses one word of its subject. The tooltip is the
answer when a title reads oddly. Sidequest docs have no category segment at all,
so only the date comes off those.
