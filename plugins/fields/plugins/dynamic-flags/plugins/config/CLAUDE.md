# dynamic-flags / config

The **dynamic-flags** type's config capability: the `dynamicFlagsField` factory
and the `flagValue` reader (core), and the renderer contributed to
`config-v2.fields.renderer` (web).

The value is a free-key `Record<string, boolean>` holding only the switches
the user set; its default is `{}`. Hosts contribute the live option set —
each option with its label and its `defaultOn` — through the
`DynamicFlags.Options` slot (matched against the field descriptor by reference
equality), and every reader applies an option's default for an absent key with
`flagValue`. So the config origin never enumerates the options, and an option
that appears later needs no migration of saved files.

Rendered as the chip cluster the panel draws for a many-option multi-select.
With no matching contribution, the keys the user did set are shown under
their raw names.
