# dynamic-flags

The **dynamic-flags** (dynamic toggles) field type of the unified fields
primitive — a set of on/off switches whose options are not fixed at
declaration time but resolved at config-render time, each option carrying its
own default.

This barrel registers ONLY the `FieldIdentity` (label "Dynamic Toggles") in the
`fields.identity` registry. It is the multi-valued sibling of `dynamic-enum`:
a standalone identity with no `extends`, because no base type's capabilities
read a runtime option set.

The type's config capability lives in the `plugins/config` sub-plugin: the
`dynamicFlagsField` factory, `flagValue`, the renderer, and the
`DynamicFlags.Options` slot through which hosts contribute the live options.
