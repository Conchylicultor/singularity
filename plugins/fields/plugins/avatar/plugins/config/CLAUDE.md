# avatar / config

The **avatar** type's config capability: the `avatarField` factory (core) and
the icon+color picker renderer contributed to `config-v2.fields.renderer` (web).

The factory builds a config_v2 `FieldDef<AvatarSpec>` carrying the canonical
`fields/` avatar token (`@plugins/fields/plugins/avatar/core`, id `"avatar"`);
dispatch is by id string. Its zod `avatarSpecSchema` parses `icon` through
`SavedSymbolNameSchema` (a Material Symbols name the installed sets draw), so a
classic key cannot be stored or read back. `migrateClassicAvatar` rewrites one
saved avatar from the classic shape (a Material Icons key + `svgNodes`) — a
config whose fields hold avatars declares a `defineConfigMigration` that maps it
over them (conversation-category, preprompts). The `AvatarSpec` value type comes
from the identity core; `FieldHeader` comes from the slot owner
(`@plugins/config_v2/plugins/fields/web`).
