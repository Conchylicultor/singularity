# text / filter

The **text** type's `data-view.filter` capability.

Contributes `DataViewSlots.Filter({ match: "text", domain: "text", ... })` —
`contains` / `does not contain` / `is` / `is not` / `is empty` / `is not empty`,
each `lower`ing its rule into the one filter language
(`network/live/plugins/filter`): `contains` → `contains`, `does not contain` →
`notContains`, `is` → `eqCi`, `is not` → `neCi` (ASCII case-folding, as the
cluster folds), `is empty` / `is not empty` → `isEmpty` / `isNotEmpty` (NULL or
ASCII-whitespace only). An empty operand lowers to `undefined` (an incomplete
rule: keeps every row, not counted). Negatives are complements, so they keep a
row with no value. Lowerings live in `web/internal/text-lower.ts`, pinned by
`text-lower.test.ts`. Derived text types (e.g. `multiline-text`) reuse this set
via the `extends`-chain fallback.
