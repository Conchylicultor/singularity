# tags / filter

The **tags** (multi-value) type's `data-view.filter` capability.

Contributes `DataViewSlots.Filter({ match: "tags", domain: "stringArray", ... })`
— `contains` / `does not contain` (one tag) and `contains any of` / `contains all
of` (multi-select chips over `field.options`), plus `is empty` / `is not empty`.
Each operator `lower`s into the filter language's `stringArray` ops: `contains t`
→ `hasAll [t]`, `does not contain t` → `hasNone [t]` (the complement of `hasAny`,
so a row with no tag set matches), `contains any of` → `hasAny`, `contains all
of` → `hasAll`. An empty operand lowers to `undefined` (incomplete). Lowerings
live in `web/internal/tags-lower.ts`, pinned by `tags-lower.test.ts`.
