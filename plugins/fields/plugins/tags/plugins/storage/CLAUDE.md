# tags / storage

The **tags** type's storage capability: contributes `Fields.Storage` (server
runtime) mapping the `tags` field token to a Postgres `jsonb` column via
`build(name) => jsonb(name)` — a JSON array of strings. Resolved by exact token
through `resolveFieldStorage("tags")`.

The builder is byte-identical to `fields/json/plugins/storage` on purpose: the
bare runtime column for both is `jsonb`, and the compile-time `$type<string[]>()`
brand is a **type-only concern with no runtime artifact** — `defineEntity`
applies it generically (`b = b.$type()`), deriving the precise select type from
the field's own schema. Baking `.$type<string[]>()` in here would be erased by
the `StorageColumnBuilder` return type (`PgColumnBuilderBase`) and carry nothing.

Without this contribution, `defineEntity` / `fieldsToColumns` throw on any
`tags`-typed field — this is what makes `tags` usable in an entity at all.
