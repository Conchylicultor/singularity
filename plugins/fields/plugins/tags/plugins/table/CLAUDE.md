# tags / table

The **tags** (multi-value) type's `data-view.cell` capability.

Contributes `DataViewSlots.Cell({ match: "tags", component: TagsCell, chip:
true })` — a read-only `TagsCell` that renders each tag in `props.values` as a
`Badge` chip on one truncating line.

Each tag reads its own option out of `field.options` (the shared `FieldOption`),
exactly like the enum twin: `label` for the text, `variant` for the tint
(default `"muted"`), `hint` for the tooltip. A tag with no matching option falls
back to its raw value, muted. `chip: true` tells the list's subtitle run to part
this term from its neighbours by spacing rather than ` · ` — see the enum
table sub-plugin's CLAUDE.md.
