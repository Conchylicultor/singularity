# date / inline

The **date** type's `data-view.cell-editor` capability.

Contributes `DataViewSlots.CellEditor({ match: "date", ... })` — a compact
`DateEditor`: an open-on-mount `DatePickerPopover`
(`@plugins/primitives/plugins/date-picker/web`) seeded with the cell's `Date`.
Picking a day commits a `Date | null`; dismissing (Esc / outside press) cancels.

A `committed` ref latches on the first outcome, so a popover that self-closes
*after* reporting the pick cannot report the close as a cancel on top of the
commit. The value stays a `Date` end to end — the only `yyyy-mm-dd` projection
is the trigger's label, via the primitive's local-midnight `toISODay`; never
`toISOString().slice(0, 10)`, which is UTC and off by a day near local midnight.

**Unreachable in the UI today**, so `web/__tests__/` is the only verification: a
cell is editable only when its `FieldDef` declares `onEdit`, and every
`type: "date"` field in the repo is read-only (`custom-columns` v1 authors
`"text"` only). The suite stands in a fake `DatePickerPopover` and pins the
wiring; the calendar's rendering and day math are the primitive's tests.
