# enum / table

The **enum** (select) type's `data-view.cell` capability.

Contributes `DataViewSlots.Cell({ match: "enum", component: EnumCell, chip:
true })` — a read-only `EnumCell` that renders the value as a chip via the
`badge` primitive. Empty values render nothing.

**Everything the chip shows comes off the matched option** (`field.options`,
the shared `FieldOption`): `label` for the text, `variant` for the tint
(default `"muted"` — the right answer for a value with no semantics, which is
every user-authored custom column), `hint` for the tooltip. A value with no
matching option — the live-registry case, e.g. a source type that is no longer
installed — falls back to the raw id, muted.

`chip: true` is this contribution's self-description, not a rendering choice:
the list's subtitle run reads it to decide separators (a chip is parted from its
neighbour by spacing, never by ` · `), so the list stays generic. It is a claim
about the field's TYPE — a consumer's `FieldDef.cell` override on an enum field
is taken to render a chip too.
