# bool / data-view-group

The **bool** type's `data-view.grouping` capability.

Contributes `DataViewSlots.Grouping({ match: "bool", label: "Group by", groupings })`
— the one way a boolean field buckets: a **No** section and a **Yes** section.

This behaviour used to live inside data-view itself (the `field.type === "bool"`
branch of `sectionLabel` in `use-data-view-sections.ts`). It is preserved here
exactly, and data-view now names no field type:

- **key** — `String(value)`, i.e. `"true"` / `"false"` — the same bucket
  identity as before, so a collapsed section survives the move.
- **label** — `Yes` / `No`.
- **order** — `false` first, matching the type's own `asc` reading ("Unchecked
  first", `boolIdentity.directionLabels`).

The type offers a **single** grouping, so the view-settings popover shows only
the field picker for boolean fields — the granularity band appears when a type
offers more than one.
