# bool / filter

The **bool** type's `data-view.filter` capability.

Contributes `DataViewSlots.Filter({ match: "bool", domain: "boolean", ... })` —
the `is` / `is-not` operator set whose value editor is a single explicit checkbox
(so the rule reads "<field> Is ☑"). A ticked box matches `true`, an unticked box
matches `false` (the default). `lower` (`web/internal/bool-lower.ts`) is always
complete — an absent operand reads as "Unchecked" — and a row with no value
reads as unchecked with no OR: `is ☑` → `eq true`, `is ☐` → `ne true` (the
complement, which keeps NULL); `is-not` swaps them.
