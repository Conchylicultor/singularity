# open-aside

Hovering a page reference reveals one button: **Open in side pane** — the
referenced page opens in a Miller column beside the page it was referenced from,
instead of replacing it. Clicking the reference itself still opens in place;
this exists as a separate button because a row's click can only carry one
intent.

The whole plugin is a `PageReference.Actions` contribution, so it needs no edit
in any of the reference renderers. Its `available` is
`nav?.openAside !== undefined`: where the host declared no second column (the
Story editor, the website's editor toy), the action is not merely disabled — it
is absent, and the reference row then paints no action cluster at all.
