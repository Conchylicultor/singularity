# agent-notes

`/agent` — the **agent → human** direction of the page's annotation channel:
what an agent wrote back (what it found, assumed, or left undone), boxed so the
reader can tell it from their own prose.

A void container (`z.object({})`, content IS its children), built on
[`page/container`](../../../container/CLAUDE.md) exactly like its
[siblings](../../CLAUDE.md) — read those two for the shape and the family's
visual language. This plugin declares only identity: a fixed `MdAutoAwesome` glyph,
the `info` dashed tint, and the `**[Agent notes]**` markdown marker.

## Not stored here: who wrote it

The card carries no author field, deliberately. Provenance has to survive edits
and be queryable, and `apps/pages/agent-origin` already owns that shape (an
entity-extension side-table keyed by block, stamped from the
`x-singularity-origin` header). A name in this block's `data` would be a second,
unjoinable copy of it.

## Nothing writes these yet

An agent has no path to author page blocks today, so today this is a block a
*human* inserts to paste an agent's output into. When agents do write pages, they
write this type — and the same delivery filter the family doc describes decides
whether it is fed back to them.
