# url-paste

A bare URL pasted at a collapsed caret (or dropped into an EMPTY block) becomes a
link at once, with a menu beside it: Keep as link / Mention (server-synced
editors only; title from `bookmark`'s `/api/link-meta`) / Create bookmark +
Create embed (only when the link is all the block holds). A URL pasted over a
selected range is `LinkPlugin`'s — it wraps the range.

## The menu closes on ANY text change

The menu stays open until a row is picked, Esc, a click outside — or **any change
to the block's text after the insert**: typing, Backspace, a remote edit, an
undo. An update listener compares the root's text with a snapshot taken right
after the insert.

Cmd+Z depends on that rule, and on nothing else. The insert is recorded as its own
undo entry (`recordDocEdit(block.id, "Paste link", …)`), and the surface undo
stack seals any open typing run before it undoes. So Cmd+Z with the menu open
pops exactly the paste: the link disappears, the text changes, and the menu
closes. There is no key interception. Remove the listener and Cmd+Z leaves a menu
offering to convert a link that no longer exists; fold the insert into the typing
run and Cmd+Z also takes back what was typed before the paste.

Mention is its own undo entry too ("Mention link"), applied only while the link
(found by node key) still has the pasted URL as both its href and its text — a
link the user edited while the title was loading keeps their edit.
