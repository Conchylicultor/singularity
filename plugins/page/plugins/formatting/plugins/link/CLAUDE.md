# link

Inline links in the page editor. Two surfaces share one `LinkForm`
(`web/components/link-form.tsx`), so URL validation (`normalizeLinkUrl`), Apply
and Remove link exist once; its fields carry `localUndoProps` (⌘Z edits the
field, not the page).

- **Selection toolbar / ⌘K** (`LinkButton`): links the selected text. URL only.
- **Hover card** (`LinkHoverPlugin`, a Plugin-only block-text extension from
  `web/internal/register.ts`): rest on a link in an editable block → globe +
  URL (opens in a new tab), Copy, Edit. Edit → URL + Title form, Enter applies,
  Remove link. Esc or a press outside closes it.

## Hover intent

All timing lives in `useHoverIntent` (`web/internal/`): open after 300 ms on a
link; close 300 ms after the pointer has left both link and card (entering
either cancels it — that grace is how the pointer crosses onto the card). Never
opens with a mouse button held (drag-select); a press mid-dwell cancels the
pending open; touch is ignored. Edit mode pins the card: the pointer no longer
closes or re-targets it. View mode never takes focus (mousedown is
`preventDefault`ed), so the caret stays put.

## Writes are single undo entries

Apply ("Edit link") and Remove link go through `useBlockEditor().recordDocEdit`
with a `discrete: true` Lexical update inside, so each is ONE undo entry fenced
off the typing run. The link is looked up by node key when the deferred edit
runs; gone by then → no-op, nothing recorded. The text is rewritten only when
the Title field changed, through `$setLinkText` from `page/editor` (one text
node, first child's marks — and never `clear()` first: a `LinkNode` cannot be
empty, so emptying it deletes the link). Remove moves the children up and drops
the link.
