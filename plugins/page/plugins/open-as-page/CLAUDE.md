# open-as-page

The block ⋮⋮ menu's **Open as page**: the block — a TODO card, a heading with
its nested lines, a toggle — opens as a page of its own in a column beside the
current one. It is editable, and every edit saves to the page that holds it (the
editor's `rootId` zoom does the scoping).

The whole plugin is one `Editor.BlockMenuItem` contribution. Where the block
view opens is not its business: it calls `PageNavigation.openBlock`, which the
host declares (`page-reference`), so this plugin never names a pane or an app.

The row is absent, not disabled, when:

- the host declared no `openBlock` — a single-surface embed has nowhere to put
  the view;
- the block is a `page` row — a sub-page already opens as itself;
- the block is the current zoom root (`useEditorScope().rootId`) — the view you
  would open is the one on screen.
