# prompt

Umbrella for the `/prompt` page block — the block **is** the prompt. Its text is
ordinary page content (editable, formattable, versioned, searchable like any
other block) and it carries a launch control that turns that text into an agent
run, without leaving the page.

Split into two sub-plugins so that the two unrelated UIs that consume the
task↔block link (the block renderer, and the task-detail origin section over in
the pages app) don't drag each other into their closures:

- **`link`** — the data layer: the `tasks_ext_prompt_block` entity extension,
  the two reads over it, the create-task endpoint, and the `pages` task category.
- **`block`** — the `prompt` block type itself: the `defineBlock` handle, the
  renderer (text editor + launch control + launched-conversation chips), and the
  server-side `data` schema registration.
