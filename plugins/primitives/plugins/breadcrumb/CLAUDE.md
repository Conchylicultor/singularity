# breadcrumb

A quiet trail: muted ancestor crumbs, a themed separator
(`BreadcrumbSlots.Separator`), and the current page as the leaf. Options:
`leafWeight` (`medium` default | `semibold` | `normal`), `leafTone`
(`inherit` | `strong`), `text` (`inherit` | `body`), trailing `actions`. The
leaf carries `data-breadcrumb-leaf`.

## The fold (`use-ancestor-collapse.ts`)

The leaf never truncates while something else can give: the ancestor run is
rigid and folds WHOLE into a `…` menu when the leaf would have to truncate, and
comes back when the trail's slack covers the open run's (cached) width plus a
4px margin.

- **It observes the trail, the ancestor run and the leaf** — every box the
  decision reads. It used to observe only the trail, so a fold taken on a
  transient (a fallback font before the web font landed, a crumb drawn before
  its theme, the separator variant arriving late) was never re-asked while the
  trail's own width stood still: the ancestors stayed behind `…` with room to
  show them. Observing the leaf cannot loop — a fold only reopens when the
  cached open width says it fits, and the open pass that follows refreshes that
  cache.
- **Widths are layout pixels**: `getBoundingClientRect` widths are divided by
  the trail's own transform scale, so an open width cached at one zoom is not
  compared against free space measured at another (a scaled canvas frame).
- Pinned by `web/__tests__/ancestor-collapse.test.tsx` against a scripted
  layout and a hand-fired `ResizeObserver`.
