# chart-kit

A hand-rolled SVG chart kit, ported from the metrics prototype
(`proto-1790501215-euqp`). It knows nothing about metrics. Its inputs are plain
data:

- `buckets: { short, label, partial? }[]` are the x positions.
- `series: { key, label, color?, values }[]` hold one value per bucket.
- `compare?: { label, values }` is the previous period.

`null` means not covered and is drawn as a gap, never as 0.

## Components (web)

- **`TimeChart`** takes `kind: area | line | stack | mirror | net`.
  - `mirror` takes exactly two series: the first grows up, the second down.
  - `net` takes one signed series.
  - `stack` values must be ≥ 0; a negative value throws.
  - A series of the wrong length throws.
  - The hover layer, the keyboard cursor and `onPick` are built in.
- **`ChartOrTable`** / **`ChartTable`** give the table twin. Rows run newest first and a click picks a bucket.
- **`Histogram`** takes `bins: { label, range, count, extra? }[]`.
- **`Sparkline`** draws a decorative trend with an end dot.
- **`ChartState`** shows loading, empty or error at the chart's height.
- **`Legend`** renders only for two or more series or a compare line.

## Rules the kit enforces

- **Mark specs** (from the dataviz skill):
  - Bars are at most 24px wide, with a 4px rounded data end and a square baseline (`offsetBarPath`).
  - Stacked segments have a 2px surface gap, and only the top segment is rounded.
  - Lines are 2px with round joins.
  - Markers have r = 4 and a 2px `--card` ring.
  - Areas are a 10% wash.
  - The grid is a 1px solid `--border` line.
- **Partial bucket:**
  - A bar is drawn at `fill-opacity` .45 and gets `data-partial`.
  - A line segment into the partial bucket is dashed `3 3`.
  - The tooltip and the table say "(so far)".
- **Colours:**
  - Series take `var(--categorical-N)` in fixed order and never cycle.
  - Past 10 series, the tail folds into "Other (k)" on slot 10 (`foldSeries`). A folded bucket with any `null` is `null`.
  - Pass `color` to pin an entity's colour.
  - Chrome uses neutral and status tokens (`web/internal/tokens.ts`): `--border`, `--faint-foreground`, `--muted-foreground`, `--hover-fill`, `--card`, `--success`, `--destructive`.
  - Text never wears a series colour. A `KeyMark` beside the text carries identity.
- **Accessibility:**
  - The svg has `role="img"` and an `aria-label` taken from the required `label` prop.
  - The svg is focusable. Focus shows the newest bucket, ←/→/Home/End step, Enter/Space picks and Esc clears.
  - Every value is also in the table twin.
- **Width** comes from `useElementSize`. The svg renders only once it has been measured.

## Units (core `format.ts`)

`count | usd | seconds | percent | lines` (the same literal set as metrics'
`Unit`, redeclared so the kit does not depend on metrics). `percent` values
are **fractions** (0.42 reads 42%). `seconds` read as the largest unit
(42s, 12.5m, 3.5h, 1.5d). `null` reads `—`.

## Exhibits

`chart-kit/time-chart` (every kind, compare, partial bucket, a gap, the table
toggle, the three states), `chart-kit/histogram`, `chart-kit/sparkline` — on
fixed September data (`exhibits/internal/september-data.ts`). All three are
`isolatedExhibit`s in the `plugin-meta/exhibits` catalog: the kit takes plain
props and reads no slots, config or live data, and its colours are static
theme CSS, so they render on a bare page as well as in the app.
