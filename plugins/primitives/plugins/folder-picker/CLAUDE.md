# folder-picker

A reusable widget for picking a directory on the **host filesystem**. Web-only:
the reads go through [`infra/host-fs`](../../../infra/plugins/host-fs/CLAUDE.md)'s
`list` endpoint, the one host-filesystem API (it owns the security model).

- `useHostDir(path)` — a thin `useEndpoint(hostFsList, …)` wrapper. With
  `path` undefined the server lists the user's home directory. The answer is
  host-fs's discriminated result: `ok` (with every entry, files and dotfiles
  included), or `missing` / `denied` / `not-a-dir` — never an empty listing
  standing in for a failure.
- `FolderPicker` — the browser block (breadcrumb + subfolder rows + confirm).
  It filters the listing to `kind === "dir"` client-side, so a symlink to a
  folder is offered as a folder; dotfolders are shown.
- `FolderPickerPopover` — a typeable path input with a live green-check /
  red-X validity indicator and a "Browse" popover. The value is an ABSOLUTE
  path: a `~/…` value is flagged invalid even though host-fs expands it,
  because the field's readers need not.

It has **no** config_v2 dependency — the `directory-path` config field type
wraps `FolderPickerPopover`, not the other way around.
