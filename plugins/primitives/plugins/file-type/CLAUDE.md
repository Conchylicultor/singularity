# file-type

What a file IS, from its name: the glyph it draws, the colour it is tinted in,
what to call it, and how it is best previewed. Plain data plus one resolver;
plan: `research/2026-10-02-apps-file-explorer-from-prototype.md` §2.

```ts
import { fileTypeOf } from "@plugins/primitives/plugins/file-type/core";
import { FileTypeIcon } from "@plugins/primitives/plugins/file-type/web";

fileTypeOf("src/index.ts");
// { icon: seti("typescript"), tone: "blue", label: "TypeScript", preview: "code" }

<FileTypeIcon name={entry.name} isDir={entry.kind === "dir"} open={expanded} className="size-4" />
```

- **Resolution order** (`core/internal/resolve.ts`, case-insensitive, last path
  segment only): a special name (`BY_NAME`: `package.json`, `.gitignore`,
  `CLAUDE.md`, …) → a name family (`BY_NAME_PREFIX`: `Dockerfile.dev`,
  `LICENSE-MIT`, `vite.config.ts`; a `docOnly` family only matches a name with
  no extension or a text one, so `todo.ts` stays TypeScript) → the extension,
  longest compound first (`foo.test.ts` before `.ts`) → the generic page glyph,
  labelled `<EXT> file` (or `File`). A special-name row without a `preview`
  takes its extension's (`README.md` previews as Markdown).
- **Glyphs** are Seti's (`seti("…")` from `ui/icons`, the vendored VS Code file
  icons). The rows follow Seti's own mapping, extended with common types it has
  no row for. Only glyphs some row names ship — the icon manifest scan reads the
  `seti("…")` literals in `core/internal/table.ts` — so a new glyph is a new row.
- **Tones** are a closed set (`FILE_TONES`), each a theme token `--file-<tone>`
  declared by `ui/tokens/file-type-palette` (Seti's palette on dark, darkened on
  light). The token group's keys are tsc-checked against `FileToneTokenKey`, so
  adding a tone without its token does not compile. `fileToneColor(tone)` /
  `FOLDER_COLOR` are the CSS colours (`var(--file-<tone>)`, `var(--folder)`).
- **`<FileTypeIcon>`**: a directory is the Material `folder` / `folder-open`
  symbol in `--folder`; a file its Seti glyph in its tone. The Seti sprite is
  not resident — the first one to mount fetches it (see `ui/icons`).
- `preview` is a HINT for a viewer registry, never a verdict: the bytes decide
  (a `.txt` that is binary is not text).
