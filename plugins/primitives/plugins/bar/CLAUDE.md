# bar

`Bar` declares a default `sm` control density for its contents (the chrome tier) — so toolbars and pane headers built on `Bar` are `sm` by construction; every leaf control, chip, and badge inside inherits it via `ControlSizeProvider`. Overridable via the `controlSize` prop; a nested region or slot can further override (innermost wins).

Tiers: `chrome` (the app toolbar, `h-chrome-bar`), `pane` (a pane header, `h-chrome-pane`, inset by the density group's `chromePanePadStart` / `chromePanePadEnd`, which default to `chromePadX`), and `subpane` (a pane's secondary strip under its header, like the conversation toolbar: as tall as its controls plus an `xs` block pad, inset by `subpanePadX`, default the `sm` step). Every inset is a density token, so a theme reshapes a tier without touching the component.
