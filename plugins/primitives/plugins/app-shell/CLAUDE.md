# app-shell

## Sidebar nav entries: `opens` (data) xor `onClick`

A nav entry (`AppShellSidebarNav`) says what a click does in one of two arms:

- **`opens: opensPane(pane, params)`** — a pane, as data. The shell opens it as
  the route root AND marks the row active (`SidebarMenuButton isActive`) while
  the route's root pane is that pane, so the current section is highlighted
  with nothing to keep in sync. Prefer it whenever the entry opens a pane.
- **`onClick`** — anything else. Never highlighted: a callback cannot say where
  it goes.

The row's geometry (height, padding, icon size, icon gap, label weight) and the
panel width are the `ui/tokens/sidebar-metrics` theme tokens; the icon wears
`--sidebar-icon` at rest and the row's text colour on hover / when active.
