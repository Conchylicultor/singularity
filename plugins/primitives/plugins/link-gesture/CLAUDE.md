# link-gesture

`linkGestureProps(open)` → `{onClick, onAuxClick, onMouseDown}` for any control
that navigates: plain click opens here, ⌘/Ctrl- and middle-click open elsewhere.

The browser grants these gestures to `<a href>` only, so a `<button>` that
navigates must read them itself — this is the single place that happens, which
is what keeps every such control agreeing on what a ⌘-click means.

A leaf on purpose (imports only React's `MouseEvent` type), so both the pane
primitive's Promote and `apps-core/tabs`' `appLinkProps` compose it without
either depending on the other.
