# grow

The **growing cell** — a box that takes the row's slack while staying floored at
its own content width, so the leaves inside it never truncate. `flex-1`, named
once.

## The four space-sharing roles

A flex child answers two independent questions: **does it take slack?** and
**does it give below its own content?**

| role | classes | axis? | the question it answers |
| --- | --- | --- | --- |
| [`rigidClass()`](../rigid/CLAUDE.md) | `shrink-0` | no | won't give at all |
| [`yieldClass(axis)`](../yield/CLAUDE.md) | `min-w-0` \| `min-h-0` | yes | gives below its content, never takes slack |
| **`growClass()`** | `flex-1` | **no** | takes slack, floors at its own content |
| [`fillClasses(axis)`](../fill/CLAUDE.md) | `flex-1 min-w-0` | yes | **= grow + yield** |

`fillClasses` is `yieldClass(axis)` + `growClass()`, pinned by a test in `fill`.

## `growClass()` vs `fillClasses()` — the floor is the whole choice

Reach for `growClass()` only when the content floor is **wanted**: the view
switcher whose chips must hug their content while only the trailing empty space
grows, an `<input>` that fills the row but stays usable, a contentful track that
must not be crushed by a neighbour.

If anything inside must ellipsize, you want `fillClasses(axis)` — `flex-1`
without `min-w-0` never shrinks below its content, so a `truncate` inside it is
**dead**.

If the box has no content at all (a spacer, a hairline rule, a coordinate track
holding only absolutely-positioned children), the two are identical — use
`<Fill>` / `fillClasses()`, which is the advertised answer and already the
sanctioned growing spacer.

## Not `GrowRelay`

[`css/grow-relay`](../grow-relay/CLAUDE.md) is the grow **request** — a widget
asking its row for room, and the boxes between relaying the ask. `grow` is a box
that takes slack unconditionally, with nobody asking.

## No axis parameter

`flex-grow` is one property that already applies along whichever axis the
container declared as main — same reasoning as `rigidClass()`. Only `yieldClass`
needs an axis, because `min-width: 0` and `min-height: 0` are two properties.
