# activity-ring

A ring drawn AROUND a status dot, saying what background work is doing while
the dot keeps saying what it already says (health, presence, …). Two states,
one ring:

- `running` — a faint track with a spinning foreground arc. Indeterminate on
  purpose: nothing it wraps today reports a percentage.
- `failed` — a broken (dashed) destructive ring.

`state={null}` renders the child alone, with NO reserved box: a ring's room
appears only while it is drawn, so an idle dot sits in its container exactly as
it would without the ring (an empty reserved box reads as lopsided padding).

The ring's diameter follows the ambient `ControlSize` through the density
group's `--status-dot-*` tokens, so it scales with the `StatusDot` it wraps.
