# scope

The app mounts the same surface more than once at a time — keep-alive tabs, floating
windows, side-by-side Miller panes. So "the thing I rendered" is never answerable by
reaching for the whole page: `document.querySelector` returns the first match in DOM
order, which may belong to a hidden background tab. Everything here answers **which
mounted instance does this belong to, and how do I reach mine?**

Reach for:

| You want | Use |
|---|---|
| Per-instance **state** in place of a module singleton | `scoped-store` |
| Per-instance **DOM node** a sibling published | `dom-scope` |
| The id naming the **surface** you are rendered in | `surface-id` |
| The id naming the **browser tab** | `tab-id` |
| The id naming the **running SPA state**, and storage keys scoped to it | `app-instance` |
| One implementation for the **whole page** (the deliberate opposite) | `install-sink` |

`install-sink` is here because it is the other half of the same decision: it is
process-global on purpose, and someone choosing a lifetime is choosing between it and
`scoped-store`. Both should be found in one place.

Not here: `primitives/shortcuts` answers the per-instance *keyboard* question, and
`primitives/dom/auto-scroll`'s `findScrollParent` answers "the scroller I am inside", which is
a different question from "the node my instance published".
