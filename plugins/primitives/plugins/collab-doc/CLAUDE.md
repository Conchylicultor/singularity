# collab-doc

## `bytea` and its wire form

`bytea(name)` (server barrel — kept off `core` so drizzle-kit's synchronous
schema loader never pulls the Lexical bridge) is the column type for persisted
Yjs doc state, `Uint8Array` on both sides. Its JSON wire form is declared once,
through sql-column's `withWire`: unfolded base64 by `stateToBase64` — the single
JS home for stored bytes → wire, which anything shipping a state by hand
(editor-collab's doc-init response) calls too, so every wire representation is
byte-identical. A row schema projecting a bytea column types the field `string`;
typing it as bytes is a tsc error at `serveCollection`.
