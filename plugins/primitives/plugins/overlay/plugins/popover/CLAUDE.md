# popover

## Closing never loses what was typed

Once a popover has been opened, its content stays mounted (hidden) while it is
closed — `PopoverContent` in ui-kit latches it — so a draft in it survives
dismissing and reopening. A popover never opened mounts nothing. Pass
`resetOnClose` only where fresh state on every open is the point: content that
seeds state once from a value that may change while closed, or that runs live
work that must stop while hidden. A draft that must outlive the host unmounting
(navigation, reload) belongs in `persistent-draft` — see `LaunchAgentForm`'s
required `draftKey`.
