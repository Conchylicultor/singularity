# html

`HtmlView` renders an `.html` / `.htm` / `.xhtml` file as the page it is, in a
sandboxed `srcdoc` iframe — the native "Page" tab, beside the code renderer's
"Code" tab, which is the page/source toggle.

The file is untrusted (anything in `~/Downloads`), so it runs in an opaque
origin (no `allow-same-origin`: no app cookies, storage or APIs) under a CSP
injected ahead of its own markup (`isolateHtml`) that admits only `https:`,
`data:` and `blob:` — its scripts run and its CDN assets load, but it can send
no request at all to the app on `*.localhost`. Relative assets (a sibling
`style.css`) do not resolve: the document has no base URL to resolve them by.
