# section-card

`children` is optional: with no body there is nothing to expand, so the card is
one static row — no chevron, no toggle, no `Collapsible` at all — carrying
`actions` beside the title. The disclosure affordance is derived from the body's
presence, never declared, so a chevron over nothing is unrepresentable.

## Two chromes: `variant`

`variant="card"` (default) is a bordered `Card` with a leading chevron.
`variant="inspector"` is a flat `<section>` closed by a bottom rule, its header a
full-width hover row with **no chevron** (`SectionHeaderRow disclosure="none"`:
the collapsed title is muted instead, and the row is still the
`aria-expanded` control). Both share the one header expression and the one
`rail-x-lg pb-lg` body, so only the frame differs. An inspector stack has no
gap and no inset — use `detail-sections`' `SectionStack`, which owns that rhythm
for the pane's declared `chrome`. Exhibits: `section-card/region`,
`section-card/inspector-region`.
