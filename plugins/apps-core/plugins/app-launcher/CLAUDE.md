# app-launcher

The top-left brand of every app, contributed once as `AppShell.Brand` — apps
never draw their own header (the shell places it; see
[`primitives/app-shell`](../../../primitives/plugins/app-shell/CLAUDE.md)).

- **Launcher** (both forms) — the current app's own mark in an icon button: its
  `Apps.App` entry's `mark` (a drawn logo) when it registers one, else its rail
  `icon`; the Equin mark (`/icon.svg`) outside any app. Each app keeps its
  identity at the top-left; the button is the same launcher everywhere. It is
  wrapped in [`HoverPopover`](../../../primitives/plugins/overlay/plugins/hover-popover/CLAUDE.md).
  Click (link gestures: ⌘/middle-click opens a new tab) → the app gallery, i.e.
  the `Apps.App` entry flagged `default` via `defaultApp()` — never named.
  Hover / ArrowDown → a 4-column grid of every other `Apps.App` entry
  (`AppIconTile`, the same tile Home draws), the current app marked; arrow keys
  move through it as a grid. A pick goes through `useActivateApp` (tabs), the
  one activation the rail and Home share. "All apps" = the icon's click.
- **`form="header"`** (sidebar header) — launcher + the current app's name, a
  link to that app's own `basePath` (not the gallery). The name is the row's
  flexible, truncating cell; the launcher is rigid.
- **`form="icon"`** (leading edge of a sidebar-less app's top chrome) — the
  launcher alone.
