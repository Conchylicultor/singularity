# emoji

An emoji as a stored value, and the picker that picks one — the sibling of
`saved-names` (a user-picked Material Symbols name). Plan:
[`research/2026-09-29-page-emoji-page-icons.md`](../../../../../../research/2026-09-29-page-emoji-page-icons.md).

- **`core`** — `Emoji` (branded string), `EmojiSchema` (THE parse that mints
  one; every store decodes through it — page block data, backlinks, search
  metadata) and `isEmoji(s)`: exactly one grapheme (`Intl.Segmenter`) matching
  `\p{RGI_Emoji}` under the `v` flag. Fully-qualified only: `🗺️` with its VS16
  passes, a bare `🗺` does not. The regex is built with `new RegExp(…, "v")`
  because the repo's tsc target (ES2023) rejects a `v` literal.
- **`web`** — `<EmojiPicker value? onSelect>` over **frimousse** (headless,
  virtualized); every pick is re-parsed through `EmojiSchema`, so a value the
  schema rejects throws instead of being stored. `EMOJI_VERSION` caps the offered
  set (15.1) below the newest emojibase release so the picker never offers an
  emoji the engine's Unicode tables — browser or Bun — cannot recognise.
  `<EmojiGlyph emoji className>` draws an emoji in an ICON's box: the `size-*`
  class sizes the box and the glyph scales to it (`cqh` of a size container),
  so an emoji and an `<Icon>` given the same class occupy the same square.
- **Emoji data is same-origin.** The server registers the `emojibase` asset
  mirror over `cdn.jsdelivr.net/npm/emojibase-data@17.0.0` (pinned, since the
  mirror caches immutably); the picker hands frimousse
  `emojibaseUrl = /api/asset-mirror/emojibase`, which fetches
  `<base>/en/data.json` and `<base>/en/messages.json` — one directory deep, the
  nested form the asset mirror serves. The browser never talks to the CDN; the
  `prewarm/` seed bakes both files into a release for an offline cold start.
  frimousse's per-session HEAD revalidation gets no ETag from the mirror, so it
  re-reads the (browser-cached, immutable) files once per session.

## Plugin reference

- Description: The <EmojiPicker>: a searchable, categorized emoji grid over frimousse whose emojibase data is served same-origin by the asset mirror; onSelect hands back a parsed Emoji. Plus <EmojiGlyph>, which draws an emoji in an icon's box (sized by the same size-* class). The page icon picker and <PageIcon> compose them. Registers the emojibase data mirror so the emoji picker's data is served same-origin (offline-capable after one warm-up) rather than fetched from the CDN by the browser.
