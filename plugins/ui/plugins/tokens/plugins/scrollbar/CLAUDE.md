# scrollbar

The colours of a theme's scrollbars. One token, `scrollbarColor`, a CSS
`scrollbar-color` value: `auto` (the default, the platform's colours) or
`<thumb> <track>`. The ui-kit's `app.css` applies it at every theme-scope root
(`:root, [data-theme-scope]`), since `scrollbar-color` is inherited.

Only the colour is themed, never the bar. Chromium keeps its native scrollbar
under `scrollbar-color` — on macOS the overlay bar: no reserved space, shown
only while scrolling, widening under the pointer — while a page-drawn
`::-webkit-scrollbar` becomes a classic bar that always takes its width (and
cannot be hidden until scroll without a script). So there are no size, radius
or hover tokens here, on purpose. A `transparent` track also removes the rail
the overlay bar draws behind its thumb while hovered.
