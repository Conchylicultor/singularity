# theme-gallery

The Theme DataView: where a user picks the theme a scope shows. It lists every
selectable theme (code themes and every resident source's) plus every browse
source's catalog entries not saved yet. Clicking one selects it for the scope
of the surrounding `ThemeScopeProvider`; a catalog entry is saved first (its
source's `adopt`).

Mounted through each host's own slot, so neither host names this plugin:

- **Customizer pane** — `ThemeCustomizer.Section` `themes`, ordered first in
  `config/ui/theme-engine/theme-customizer/section.jsonc`. Cards, plus rename
  and delete on saved themes.
- **Quick-theme popover** — `QuickTheme.Section` `themes`. Compact rows in a
  bounded scroller, no row actions: a modal confirm opened from a popover would
  close the popover that launched it.

Why not import the picker straight into the customizer: this plugin
contributes to quick-theme, which imports the customizer's route, so the
customizer importing back would close a cycle.

## Two surface ids, one component

`ThemeGalleryView` is the one DataView component. The pane and the popover pass
their own surface id (`theme-engine.themes`, `theme-engine.themes.quick`),
because one id means one view config, and the popover must not offer the
pane's card views. To the user it is ONE list: both configs author the same
views (My themes / Community / Curated) with the same filters, and differ only
in view type — keep them in step. A row's body follows that type: `gallery`
draws `ThemeCard`, `list` draws `ThemeSwatch`.

## Rows (`web/internal/theme-rows.ts`, pure, tested)

- A catalog entry that is already saved (`savedThemeId`) is not a second row:
  the saved theme stands in for it, with the entry's tags and catalog, at the
  entry's position — so the card a user just picked stays where it was.
- The `Community` views filter on `catalog` (the browse sources listing a
  theme), not `source`: a picked catalog theme's `source` becomes `tweakcn`,
  and it must not vanish from the view that offered it.
- Field options come from the rows, so the gallery names no source and no tag.
- Keys are prefixed by kind (`theme/<id>`, `entry/<source>/<entry>`), so the
  two key spaces cannot collide.
