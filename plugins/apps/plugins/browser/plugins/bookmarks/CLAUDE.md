# bookmarks

The browser's bookmarks: the `browser_bookmarks` table, the star toggle in the
chrome actions and the bookmarks bar below the omnibox (the start page's
Bookmarks section reads the same collection).

- **`browserBookmarks`** (`core/resources.ts`) is a `liveCollection`: a bounded
  window, oldest first (`createdAt asc`), 100 by default and at most 500, plus
  its `:rows` point sibling. `url` is its one filterable column.
  `server/internal/resource.ts` serves it with
  `serveCollection(browserBookmarks, { from: _browserBookmarks })` — every row
  field is a column by name, since the table and `BookmarkRow` both derive from
  `bookmarkFields` — and the server barrel spreads `...browserBookmarksServed.declare`.
- **Readers.** The bar (`useBookmarks()`) and the start page read the default
  window with `useLive(browserBookmarks)` and offer `loadMore` once it is full.
  The star reads ONE url — `useLive(browserBookmarks, { where: { url }, limit: 1 })`
  via `useBookmarkToggle(url)` — never a scan of a window, which would miss a
  bookmark past its first page. While pending the star is disabled and has no
  `toggle`, so a click cannot add a duplicate.
