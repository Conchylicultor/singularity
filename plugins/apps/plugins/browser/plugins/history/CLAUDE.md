# history

Records every browser navigation into `browser_history` (the headless
`RecordVisits` effect → `POST /api/browser/history`), and serves the start
page's "Recent" list.

- **`browserRecents`** (`shared/resources.ts`) is a `liveValue`: the latest visit
  per distinct url, newest first, capped at 12. It is a value rather than a
  `liveCollection` because it is a derivation (`DISTINCT ON (url)`, re-ordered
  and limited), not rows of one table. `server/internal/resource.ts` serves it
  with `serveValue({ source: "db" })` — recomputed on every write to
  `browser_history` — and states the loader's LIMIT as its
  `unbounded: { reason }`. Readers use `useLive(browserRecents)`; there is no
  placeholder, so it is `pending` until the first value lands.
