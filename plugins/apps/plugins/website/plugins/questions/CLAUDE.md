# questions

The two pages the homepage forks into — one per question the site asks.

The homepage states a bet and then splits, because the two claims it makes have
different audiences and different answers. Each question owns one plugin here:
its `/website/<segment>` pane, its nav link in the shared site header, and its
own `Section` render slot, so the answer can be written later as contributions
without touching the page plugin.

Both pages are deliberately near-empty today. A page whose sections have not
been written yet should read as unwritten — never as a placeholder ("coming
soon") and never as an error.
