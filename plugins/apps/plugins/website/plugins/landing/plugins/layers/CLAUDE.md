# layers

"What is equin?" — the homepage's map of the project as three stacked layers
joined by arrows: the technical foundations, the applications built on them
(grouped by category, future apps dimmed), and the vision of one OS-like
surface.

Each layer is one click target opening its page (`pages/foundations`,
`pages/apps`). A layer must SAY it can be opened before it is hovered: the round
arrow at the end of its title row is always visible, and the hover lift and the
arrow's step forward (`layers-section.css`) only confirm it. Do not rely on
hover alone — a touch screen never shows it.

The app list is plain data in the component: a closed list someone writes, not
a collection plugins contribute to.
