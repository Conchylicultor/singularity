# refresh-all

**Refresh all** — one button that asks every *enabled* source for a run.

A **pane** action, not a row one. It is a set operation over the whole list, and
the set is the thing being acted on: "refresh everything" said once per row is
not the same gesture, it is N gestures with N confirmations to read. The button
therefore lives in `eventSourcesPane.Actions`, which is also why this is its own
folder — the sources pane knows nothing about refreshing, and deleting this
plugin deletes the button with no edit there.

## Disabled sources are not candidates

The server never asks a disabled source, and it counts nowhere in the tally.
Disabling is the user saying *"not this one"*; a bulk refresh that overrode it
would make the toggle mean "except when I press the big button", which is to say
mean nothing. The same reasoning that keeps a disabled source out of the
scheduler keeps it out of here.

`skipped` can still be non-zero — a source disabled *between* the server's
listing and its own enqueue. Rare, racy, and a genuine refusal of a request we
did make, which is why it is a count rather than being folded into silence.

## The tally is rendered arm by arm

`RefreshAllResult` is `{ enqueued, alreadyRunning, skipped }` and `describeRefreshAll`
renders every non-zero term, the same discipline `source-detail/schedule` applies
to the single-source `RefreshSourceResult`. A resolved promise is **not**
"everything refreshed":

- all three zero → "Nothing to refresh" — the honest answer, and deliberately
  not a success chirp;
- `alreadyRunning` → the request joined a run already in flight, it did not
  start a second one;
- `skipped` → colours the toast, because it is the only arm the user might act
  on.

The toast is never `success`: what succeeded is the *enqueue*. The runs have not
happened yet, and they surface as they land, off the `events.runs-revision` tick.

A failed request is left entirely to the global mutation toast
(`useRefreshAllEventSources` passes no `onError`, so `useEndpointMutation` keeps
it armed) — reporting it here as well would double-report one failure.
