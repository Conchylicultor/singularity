# source-field

The `source` dimension of the events DataView, contributed into `event-list`'s
`EventList.Fields` seam. `event-list` names no source and no source type; this
plugin owns the option list because only it holds the live `event_sources` rows.

**The field id is `sourceId`, not `source`** — it must match the physical column
already bound in `event-list`'s server `COLUMN_MAP`, which is what makes filter
and sort compile to SQL. Rename it and the dimension silently degrades to
client-side-only over the loaded page.

A component, not plain data: `FieldDef.value` is synchronous and cannot call
hooks, so a hook-loaded option list has to be produced from inside a mount. Same
shape as `tasks/task-category`'s `CategoryField`.
