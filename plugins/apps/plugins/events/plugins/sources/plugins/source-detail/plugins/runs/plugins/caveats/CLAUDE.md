# caveats

What the extraction **could not express**, as one section of the run pane.

The event date format holds a rich but *closed* rule vocabulary. A page saying
"every 2nd and 4th Tuesday" or listing irregular dates falls outside it, and
`flags` is the channel the extractor reports that on. This section reads it.

## Why it lives here and not in `runs`

Same reason as its sibling `model-call`: the run ledger is generic over source
types, and only some source types extract at all. So it is a contribution into
`runs`' `EventSourceRunDetail` slot, reading `flags` off the ledger row — a field
of the run, not of any source type. `runs` names no extractor.

## Flags are global to the extraction, never per event

`flags` describes the parse *session* ("this page lists an irregular date series
I cannot represent"), so the section shows a flat list with no event beside each
entry — attaching one would invent a link the model never made.

`unchanged` / `failed` runs carry `flags: []`: neither re-read the page. The
source's `lastFlags` (Status card) is the one that survives an unchanged run.

## Three arms, and the empty one is the healthy one

- **error** — the run fetch failed; its own message, never an eternal skeleton.
- **pending** — `<Loading variant="rows" />`. The empty copy here would state "no
  limitations" about flags that had merely not arrived.
- **empty** — the extraction reported nothing it could not express. The copy says
  outright that this is **expected**; read as a gap it sends someone hunting a
  bug in the healthy case.

Always available (`useAvailable` → `true` unconditionally, the `source-detail`
house rule): a card appearing only once flags exist would pop in after the fetch,
and its absence would be indistinguishable from "still loading".

Each flag gets its own sunken surface in a flow container, so two read as two and
a long one wraps rather than widening the pane. The text is the model's words
verbatim — there is no vocabulary to summarize it against, which is why the
channel is free text.
