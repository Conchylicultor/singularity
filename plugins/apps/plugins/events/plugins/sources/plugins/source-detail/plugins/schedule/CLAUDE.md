# schedule

Cadence + scheduling on/off + **Refresh now** for one source.

`RefreshSourceResult` is a discriminated union and every arm is rendered
(`describeRefresh`, exhaustive `switch`): a resolved promise is **not** success
here — `already-running` and `skipped` are legitimate non-runs with different
meanings, and collapsing them into "done" is the exact bug the union exists to
prevent. A 503 (no refresh engine installed) is an error, not an arm, and shows
as the endpoint's own message.

Cadence writes go through the source row's `nextRunAt` watermark server-side, so
a cadence change takes effect without touching the cron.
