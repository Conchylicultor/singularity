# status

Current state of one source: the status chip, the run watermarks, the probe
fingerprint, and — when the source is parked — the classified terminal error
**verbatim**.

`lastError` only ever holds a TERMINAL failure (a transient one stays on the run
row), so when it is set it is the reason the source stopped, not noise. Rendering
it in full is the point; there is no per-code remediation copy because the error
vocabulary is server-private to `events/refresh`.

The chip rides as `summary`, so the state stays readable with the card collapsed;
the card opens by default only when the source is errored.
