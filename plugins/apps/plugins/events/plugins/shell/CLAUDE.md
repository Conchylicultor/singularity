# shell

App shell for the Events app. Registers the `/events` app entry (rail icon
`MdEvent`, tooltip "Events"), defines the `Events.Sidebar` render slot for
left-rail surface entries, and registers the index pane (`events-root`,
`appIndex: true` so bare `/events` lands here).

Sidebar-only, no app toolbar (the Pages/Settings shape): the active pane's own
`PaneChrome` header owns the surface top and hosts the sidebar toggle, rather
than stacking an empty chrome bar above it.

The shell names **no** feature sub-plugin; everything visible arrives through
`Events.Sidebar` (import direction `<feature> → shell`, never back). Hence the
landing pane's call to action is prose pointing at the sidebar rather than a
button linking into the `sources` plugin's route — that route is `sources`' to
own.

Design: [`research/2026-08-03-apps-events-event-tracking-app.md`](../../../../../research/2026-08-03-apps-events-event-tracking-app.md).
