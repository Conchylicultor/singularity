# excluded

Badges an explorer tree row that the **app does not ship**. The tree lists every
plugin on disk, so without this the rows for the twelve plugins outside the
bundle look exactly like the rows for the ones running.

Two labels, because the two cases are answerable and different:

- **Not in the app** — a manifest negated this id by name. In practice that is
  the `base-exclusions` row in
  [`composition/core/config.ts`](../../../../../../plugin-meta/plugins/composition/core/config.ts),
  which every composition inherits.
- **Not in the app (cascade)** — nobody named it; it descends from, or
  transitively imports, something that was named, so removing that removed this
  too (`removalClosure`).

Both come from `useAppExclusions()` (`composition/web`), which resolves the
`singularity` composition in the browser from the edge graph and the manifests
the client already holds. Nothing about membership travels on the wire, so this
badge and the codegen that emits the registries read one implementation of one
rule.

While that resolve is pending the row shows a small shimmer rather than nothing:
"no badge" is the answer for a plugin that DOES ship, and rendering it before the
answer is known would be a claim that reverses itself a moment later.

The badge self-filters per node (`if (!excluded.has(node.id)) return null`), the
shape every contribution into `Explorer.TreeRowBadge` uses — the slot renders
every badge for every row and each one decides whether it has something to say.

## Not the same thing as `membership`

The sibling [`membership`](../membership/CLAUDE.md) sub-plugin tints rows by the
composition **draft currently being edited** in the Compositions pane. This one
answers what the **built app** contains. "What I am composing" and "what ships"
are different questions about the same tree, so they are deliberately kept apart:
separate plugins, separate slots (accent tint vs. trailing badge), and no shared
colour — a row tinted `excluded` by a lean draft you are experimenting with is
usually a plugin that ships perfectly well.
