# version

The `version:` counterpart kind for the prototype Compare stage: another
version of the same prototype, beside the version on screen.

- `version:latest` — the live folder. It reloads on every edit, like any live
  frame.
- `version:<sha>` — a recorded version, frozen.
- `version:shown` — the version on screen (the mock half's own document), as
  **another variant**: it follows the stepper like the mock half, but holds
  option picks of its own. They start as the shared picks and are changed from
  the **Variant** popover the half puts in the stage's bar (its `controls`), so
  the pane's options picker keeps driving the left half and a pick on the right
  writes nothing to the shared record. A version with no options resolves to
  an unresolved notice.

Nobody writes this kind in a page, so the contribution has no `example`. It is
offered two ways instead:

- **The stage's Against control** lists it as "Latest version" and "Another
  variant" (the contribution's `presets`).
- **The version list** (the popover behind the stepper's `v3 of 7`) gets a
  **Compare with latest** hover action on every row except the latest one. It
  shows that row's version on the left, picks `version:latest` on the right,
  switches to Compare and closes the list. The ‹ › arrows then keep stepping
  the left half through history while the right stays on the latest.

Both halves go through the same frame (`MockFrame`) at the prototype's declared
viewport, with the same picked options — each judged against its own version's
declared options (`usePrototypeDocumentSrc`) — so the two differ by the version
alone.
