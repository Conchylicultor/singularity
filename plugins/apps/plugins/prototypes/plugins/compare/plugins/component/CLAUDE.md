# component

The **`component:`** kind of counterpart for the prototype canvas's Real app frame: a
real app component, exhibited by the plugin that owns it as a **specimen**
(`plugin-meta/specimens`), rendered inline in the running app.

```html
<meta name="mocks" content="component:task-draft/composer" />
```

## Why not `fixture:`

A layout-harness fixture is also a geometry test case, rendered in a bare page
with no plugin runtime — so a component whose content comes from slots, config
or live data cannot be one. A specimen renders inside the app itself, so the
Improve composer's model / thinking / preprompt pills and its element-picker
button are the real contributions.

## What it resolves to

- **unresolved** when no plugin here exhibits that id (ordinary: prototypes are
  shared by every worktree, specimens are per-branch code), or when several do
  (ids must be unique; the clash is shown, never resolved by load order).
- **found**, with the specimen's own `widths` (fallback `360 / 640 / 960`)
  merged with the prototype's declared width, and `render: () => <Specimen/>`.

No loading arm: the registry is a slot, complete once plugins have booted.
