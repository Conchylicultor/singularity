# exhibit

The **`exhibit:`** kind of counterpart for the prototype canvas's Real app
frame: one real app component, looked up by id in the exhibit catalog
(`plugin-meta/exhibits`) and rendered inside the running app.

```html
<meta name="mocks" content="exhibit:task-draft/composer" />
```

The id is any exhibit's — from any plugin's `exhibits/` folder, `isolated`
(renders anywhere; the former layout-harness fixtures) or `app` (needs the live
app's slots, config and data; the former specimens). Both render here through
`<ExhibitView>`, so an app exhibit's pills and buttons are the real slot
contributions.

## In which app's theme: `@<app path>`

An exhibit renders inside the Prototypes app, so by default it wears the
Prototypes app's theme. A mock of how one app looks names that app after an
`@`, as the app's in-app path (the same spelling the `route:` / `app:` kinds
use):

```html
<meta name="mocks" content="exhibit:ui-kit/menu-sheet@/agents" />
```

The kind resolves the path to the app that owns it (`resolveAppForPath`) and
renders the exhibit inside that app's `<Theme name={appThemeScope(id)}
surface="canvas">` boundary: the app's own tokens, icon style and canvas, carried
into every menu or popover the exhibit opens. Nothing is copied — the theme
engine already emits a scoped block for every registered app — so the frame
shows the app's theme as it is now, and follows any change to it. A path no
app owns, or one without a leading slash, is an **unresolved** frame, never a
silent fallback to the Prototypes theme.

## What it resolves to

`useExhibit(target)` answers, and each answer is a frame state:

- **loading** while the catalog (loaded once per page) is not in yet — never
  "no such exhibit", which would be a claim that reverses itself.
- **unresolved** when no plugin here exhibits that id (ordinary: exhibits are
  per-branch code), or when several do (ids must be unique; the clashing labels
  are named, never resolved by load order).
- **found** — title = the exhibit's label, subtitle = its description, badge =
  its id (plus the app's name with `@`), `render: () => <ExhibitView exhibit/>`
  (inside the app's theme boundary with `@`).

An exhibit's `widths` do not reach the frame: the canvas owns the frame's size
(its presets, Responsive, Custom), so the exhibit renders at whatever size the
canvas is set to. A region exhibit renders with `<ExhibitView>`'s neutral sample
rows in its hole.
