# open-in-app

The way *out* of a borrowed page-detail pane.

`pageDetailPane` is reusable chrome — the agent manager mounts it as a Miller
column beside a conversation (`agent-manager/pages-nav`), and any other app may
do the same. Read there, a page is a **peek**: the surrounding app's own columns
are what the user is actually working in, and the page has none of its own
surface (no tree, no search, no landing). This plugin is the affordance that
promotes the peek into the real thing.

## Why the visibility check, and why that hook

The action renders `null` when the current app is already Pages. "Expand to
Pages" from inside Pages is a no-op, and a button that does nothing is worse
than an absent one — the star and history buttons beside it always act.

It reads `useCurrentAppId()` (apps-core) rather than the URL or
`useFocusedAppId()`, because that hook resolves **surface-first**: it answers for
the tab this pane is rendered in, not for whichever tab currently has focus.
Tabs are kept alive while backgrounded, so a focus-derived answer would flip
this button on and off in every background tab as the user switches tabs.

## Why a button and not an `<a href>`

The target is an *in-app* tab, which the browser knows nothing about. A real
anchor's middle-click would spawn a **browser** tab that cold-boots the whole
SPA — landing the page beside the workspace instead of inside it. So the control
stays a button and the link gestures (plain click / ⌘-click / middle-click) are
read explicitly, via `appLinkProps()` from `apps-core/tabs` — the one definition
of those semantics, so every future in-app link agrees with this one.

## Plugin reference

- Description: Expand action in the page-detail header, shown only when the page is open outside the Pages app: takes it to Pages in this tab, or in a new one on middle-/⌘-click.
- Web:
  - Contributes: `PageDetail.HeaderActions` → `OpenInAppAction`
  - Uses:
    - `apps-core.useCurrentAppId`
    - `apps-core/tabs.appLinkProps`
    - `apps/pages/page-tree.PageDetail`
    - `primitives/icon-button.IconButton`
