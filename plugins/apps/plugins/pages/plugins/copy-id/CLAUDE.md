# copy-id

A "Copy block ID" button in the page-detail header, next to the favorite star
and version history. One click puts the open page's id on the clipboard, so it
can be pasted into a prompt for an agent's `read_page` / `edit_page` tools.

A page is a block: its `pageId` is the block id those tools take. It is the
page-level twin of the gutter menu's "Copy block ID"
(`page/editor`'s block actions menu), which copies the id of one block inside
the page.

The feedback is the button's own check-mark flash — the button stays on screen
after the click, so no toast is needed (the gutter menu toasts only because its
popover closes on commit).
