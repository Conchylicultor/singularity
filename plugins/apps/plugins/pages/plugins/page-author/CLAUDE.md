# page-author

A sparkle-icon button (`MdAutoAwesome`, the `/agent-page` icon) in the page-detail header, between version history and "Copy block
ID". It shows whether the open page is an agent page, and one click switches it.

- On an agent page it is blue and pressed. Tooltip: "Agent page: agents can write
  all of it. Click to make it a normal page."
- On any other page it is a plain ghost icon. Tooltip: "Make this an agent page:
  agents will be able to write all of it."

An agent page is one an agent may write in full: its page row carries
`author: "agent"` (the `<agent-page>` of `page/annotations/agent-notes/agent-page`).
A click calls `setPageAuthor` with the other value. That is the one way a page's
author changes after the page is created — an ordinary data write cannot change
it. The button waits for the server rather than flipping at once. The icon changes
when the live pages list updates, which is also what re-tints the page's row in
its parent page and in the sidebar.

While the pages list is still loading, the button's place shows a same-sized
placeholder, never the unpressed button. An unpressed button would say "this is
not an agent page" before that is known.

**This button is the only sign on the open page that it is an agent page.** That
is the user's choice: no banner, no chip. From outside the page, the blue row in
the parent page and in the sidebar still say so.

## Why it lives here

- **Under `apps/pages`, not in the `agent-page` plugin.** The header strip
  (`PageDetail.HeaderActions`) belongs to the Pages app's page pane, which is app
  chrome. The `plugins/page/**` plugins are the editor the app is built on, and
  none of them imports an `apps/**` web barrel, so the button cannot be
  contributed from there without inverting that layering.
- **Named `page-author`, not "agent page".** "Agent pages" already names
  something else in this app: `apps/pages/agent-origin` marks pages that an
  automated browser session created (swept after a day). The button sets the
  page's `author`, so it is named for that.
