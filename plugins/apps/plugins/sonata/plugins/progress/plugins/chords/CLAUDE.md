# chords

The chord lane above the Sonata progression rail: one chip per chord annotation, placed in the scrubber's `LANE_ABOVE_Y` band and sized by the chord's beat span, labelled in the shared chord-label mode, with the chord under the playhead accent-tinted.

- **Follows the session score** (the marker's `score` prop), so the labels follow transpose; labels are memoised on score + mode.
- **No per-frame renders**: the current chord is a `useCursorSelector(beat → index)` (`chordIndexAt`, a binary search), so the lane reconciles only when the playhead crosses a chord boundary, and each chip is memoised (two chips re-render per crossing).
- **Pointer-transparent**: pressing the lane scrubs like the rail (the band sits in the slider's reserved top room).
- **Labels are clipped, never ellipsized** — and a label that does not fit its chip is hidden whole (a flex-wrap trick, no measurement), since a clipped `Cmaj7` reading `Cm` would name the wrong chord.
- A chordless song renders nothing; the scrubber reserves the lane's room regardless, so the strip height never changes.
