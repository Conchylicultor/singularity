# voicing-controls

The voicing **part** of the Sonata Accompaniment section: `VoicingControls`
renders two rows over the GLOBAL `voicingConfig` — "Voice-leading" (a
`Switch` over `realistic`) and "Octave" (a − C4 + stepper over `octave`,
clamped 1–7). Both labels carry the tooltip "Applies to every song", since the
config is not per song.

## Design

- **A part, not a section.** The plugin contributes nothing; the Accompaniment
  section (`rich/plugins/accompaniment`) imports `VoicingControls` from this
  barrel and owns the header, the chrome and the applicability gate. A fixed
  composite, so a direct import rather than a slot.
- **No gate here.** The gate is the song document's `useHasVoicedChords`
  (`apps/sonata/document/web`: an authored chord, or chord mode on with any
  chord); the composing section reads it. This component never returns null.
- **The tone order is not here.** Which figuration each hand plays is per song
  and lives in the rhythm groove panel (`rhythm-controls`).
