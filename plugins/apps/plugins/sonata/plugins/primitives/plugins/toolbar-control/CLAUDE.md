# toolbar-control

The shared chrome for Sonata's toolbar "dial" controls — the speed/spread jog
wheels (`jog-wheel`) and the transpose stepper. A compact bordered pill with a
leading, muted category icon and a row of caller-supplied segments.

`ToolbarControl` (from the `web` barrel) owns the rounded border, the tooltip,
the no-song disabled dimming, and the leading icon's horizontal clearance from
the rounded corner — so its glyph never crowds the border (the bug this frame
exists to make structurally impossible across every toolbar dial). Pass the
already-sized `icon`, the `tooltip`, an optional `disabled`, and the segments as
`children`. Segment dividers (`border-l`/`border-x`) live on the segments, not
the frame, so each control divides its interior however it likes.

## Hover-expand: the one fold rule

A collapsible toolbar control folds part of itself away at rest — the jog
wheels' ribbed face, the volume slider — and every one of them opens and closes
by the same rule, owned here so it is never re-spelled:

- `hoverExpandHost(held?)` — spread onto the box whose hover opens the fold (the
  whole control). `ToolbarControl` does it for you with `hoverExpand={{ held }}`.
- `<HoverExpandPanel>` — the folded part. Open while the host is hovered, has
  focus within, has a pointer pressed inside it (`:active` — a native slider
  drag), or is `held` (a jog wheel passes "drag not idle", so a flick or a coast
  never snaps it shut). It animates to its content's own width (a `0fr → 1fr`
  grid track), so the caller sizes the content and restates no width.
