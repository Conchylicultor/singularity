# source-line

`SourceLine` names a loaded source in the Sonata player's inspector — the
Ultimate Guitar tab (song / artist / Replace) and the Recording's video (title +
match badge / channel / Replace).

```tsx
<SourceLine
  title={tab.songName}
  badge={<Badge …/>}          // optional, inline right after the title
  subtitle={tab.artistName}    // optional, muted second line
  action={<Button variant="ghost">Replace</Button>}
>
  {open ? <UrlRow /> : null}   // optional expanded area below
</SourceLine>
```

Layout: the title and subtitle stack in the one flexible cell (each a single
line that truncates; the badge never shrinks), the action is a rigid trailing
leaf vertically centred across both lines, and `children` render below the
whole line. The caller owns any open/closed state for the expanded area.
