# app-cards

Contributes the launcher grid to `Home.Section`: one tile per registered app
(read generically via `Apps.App.useContributions()`, excluding the Home app
itself via `useCurrentAppId()`).

The grid is a `DataView<ActiveApp>` in the `icons` view (the shared
`primitives/data-view` surface), so it gets search, filter, sort, drag-to-reorder
and view-state persistence for free. Each app is two fields: a leading avatar
field (`avatarFieldDef`, squircle, the app's declared `AppIcon.color` or a
colour derived from its id) that the icons view draws as the tile, and a `text`
`name`. The toolbar is the `capsuleToolbar` arrangement.

The "New app" affordance is wired via the `creators` prop (the capsule's round
button) and the no-match empty state's "Build one?"; both call a stub until a
create-app flow is designed.
