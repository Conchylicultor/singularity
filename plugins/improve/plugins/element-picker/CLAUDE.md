# element-picker

The element picker wired into Singularity's Improve flow — two buttons, both
`PickerButton` from `primitives/ui-context/element-picker`:

- **Improve pill** (`MdAdsClick`, "Pick UI element") — the second segment of the
  action bar's `[✦ Improve | ⌖]` split pill (`ImproveSlots.Segment`): pick an
  element, then insert its `<ui-context …>…</ui-context>` tag into the Improve
  draft via `insertIntoImproveDraft`, opening the popover if it is closed.
- **Task-draft form** ("Attach UI element") — inject the tag at the head card's
  caret, so several picks in a row land as several chips.

Everything generic lives in that primitive: the overlay and its hit-testing,
the slot-contribution lineage stamping, and the `<ui-context>` chip itself (so
the same chip renders in the draft, the sent message and assistant text). Read
its `CLAUDE.md` before changing how picking works.

## The `vite/` source-location transform

`vite/index.ts` is a Babel plugin that stamps two attributes the picked token
reads (token format: `primitives/ui-context`'s `core/internal/token.ts`):

- `data-source` → the `source` field: repo-relative `file:line` of the **leaf**
  host element where the JSX tag is literally written.
- `data-ui-owner` → the `owner` field: `Name@file:line` of the nearest
  **semantic** component that owns the element (prepended on component
  callsites, so it rides the composed primitive's `{...props}` spread and
  base-ui's `data-*` forwarding onto the host). This names the *composing*
  component (e.g. `LaunchControl`) for picks where it authors no host element of
  its own and is not a slot contribution — exactly the case `source` (a leaf
  primitive) and `plugin`/`contribution` (the outer slot wrapper) both miss.
  Omitted when the element doesn't flow through a prop-forwarding primitive.

`web-core` discovers every `**/vite/index.ts` by a **filesystem walk**, not by
composition, so both attributes are stamped in every build of every composition
— including one that does not contain this plugin (the equin website's picker
gets `source`/`owner` from it).
