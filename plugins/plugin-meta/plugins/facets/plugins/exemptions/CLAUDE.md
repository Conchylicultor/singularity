# exemptions

Docs facet over the inverted exemptions (`framework/tooling/exempt`): per plugin,
what it exempts itself from (read from its own `exempt/index.ts`), and — on the
plugin that owns a lint rule or check — who exempts themselves from it, with the
debt count. The compact plugin index marks a plugin carrying a manifest with
`[exempt]`.

`extract()` loads the plugin's manifest and records which rules it owns (the
`name` of its `lint/index.ts` contribution, the check ids its `check/` declares);
`relate()` resolves each exempted rule id to its owner and builds the reverse
index. Interactive view: `./singularity exempt list`.
