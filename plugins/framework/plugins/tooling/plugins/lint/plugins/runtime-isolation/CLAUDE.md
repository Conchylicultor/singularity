# runtime-isolation

One repo-wide ESLint rule policing imports **inside a single plugin's own
tree**:

- **`no-deep-own-folder-import`**: a browser-built file (`web/`, `core/`,
  `shared/`, `fixtures/`) reaches a sibling folder only through its barrel —
  `../../core`, never `../../core/merge-group-values`. See below.

It reads the plugin-dir grammar through `lint/own-tree.ts`.

Which own folder a runtime may import at all (`core/` never reaching its own
`server/`, and so on) is not a lint rule: `boundary-rules`
(`tooling/boundaries`) applies the runtime table to relative imports inside a
plugin exactly as it does across plugins. That check is what stops a repeat of
the `conversations/core` → `../server/status` stale-bundle outage
(`research/2026-08-17-global-artifact-address-covers-content.md`).

## Why deep own-folder imports are banned in browser-built files

The web-artifact builder turns every import into another own folder into that
folder's barrel artifact (`@plugins/<own>/core`). It cannot inline the file:
the page would then hold a second copy of that file's module state, next to
the one inside the core artifact every other plugin loads. So in the browser
`../../core/merge-group-values` means "the core barrel", while `tsc` reads it
as the file.

That is how `theme-engine/web/components/theme-injector.tsx` shipped: it
imported `mergeGroupValues`, which `core/index.ts` did not export. Type-check,
eslint and plugin-boundaries were all green. `./singularity build` failed about
5 minutes in, at compose: `"@plugins/ui/plugins/theme-engine/core" does not
export "mergeGroupValues"`. Written as the barrel, the import means the same
thing to `tsc` and to the bundler, so the missing export is a type error in the
editor. The autofix rewrites the specifier to the barrel — the module the
browser already loads — and `tsc` then names whatever the barrel still lacks.

Server, `check/`, `cli/` and script files are out of scope: they run under Bun,
which loads the deep file itself, so their deep imports mean what they say. The
builder also throws on a deep path (`web-artifacts` `ownFolderBarrelPlugin`), as
the backstop for what lint cannot see — generated files, disabled lines,
`--skip-checks`.
(`research/2026-09-15-global-own-folder-barrel-imports.md`)
