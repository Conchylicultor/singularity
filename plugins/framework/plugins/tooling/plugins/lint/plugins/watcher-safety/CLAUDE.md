# watcher-safety

Every file watch in host-process code goes through the file-watcher primitive
(`infra/file-watcher`): `defineFileWatcher` in a backend (declared, described,
listed in Debug → Background activity), `watchForCommand` in a foreground CLI
command.

- `no-direct-parcel-watcher` — only the file-watcher engine
  (`infra/file-watcher/shared/`) value-imports `@parcel/watcher`, so the
  release's vendored native addon is honoured.
- `no-raw-fs-watch` — no `fs.watch` / `watchFile` / `unwatchFile` /
  `fs.promises.watch` (named, namespace, default or `fs/promises` imports) and
  no chokidar in `/server/`, `/central/`, `/shared/`, `/cli/`, `/bin/` code
  (tests exempt). Exceptions sit in an `exempt/index.ts` manifest, each with its
  reason — today only the build admission valve's one-latch-file wake.
