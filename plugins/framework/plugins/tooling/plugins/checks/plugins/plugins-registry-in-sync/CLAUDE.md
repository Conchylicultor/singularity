# plugins-registry-in-sync

Two assertions about the committed `<dir>.generated.ts` registries.

1. **In sync with source** — each equals `renderCollectedDirRegistry({ ctx, def })`.
2. **Equal to the `singularity` composition's closure** — the same render with
   `bundle: <that closure>` is byte-identical. Main is an ordinary manifest entry
   whose entry points are `["**"]`, so filtering by its closure must change
   nothing; this is what makes "main is a composition" an enforced fact rather
   than an assertion. The failure names the plugin ids the committed registry
   carries that the closure does not reach.

The registries themselves stay a pure function of the filesystem +
`singularity.disabled` — this check proves the two paths coincide, it does not
merge them.
