# format-clean

Fails if any `.ts`/`.tsx` changed on this branch (vs `merge-base(HEAD, main)`,
plus dirty/untracked) differs from prettier's output. Fix with
`./singularity format` — seconds — or `./singularity build`, which runs the
identical pass.

The changed set and the format come from
[`tooling/format`](../../../format/CLAUDE.md), never recomputed here: if the
writer and this checker disagreed about the set, the build would format one and
the check would assert another.

Two flags it deliberately does NOT set:

- **`inputKeyed`** — requires the whole read surface to go through the recording
  `FileSystemView`, and the first read is `git merge-base`, a ref read the view
  cannot observe. It would be a stale-PASS hole.
- **`alwaysRun`** — on the build path it is structurally green, since the build
  formats before anything hashes.

`cacheSignature()` folds the merge-base sha because the working-tree hash the
runner caches a PASS on does not cover git refs: main advancing moves the
merge-base and therefore the changed set.
