# format

`./singularity format` — prettier over the `.ts`/`.tsx` changed on this branch.

The first command expressed as a plugin contribution, and the reference shape
for the rest: `cli/index.ts` is the data-only declaration, `cli/run.ts` is the
implementation it reaches through a lazy `import()`. The declaration loads on
every `./singularity` invocation; `run.ts` loads only when this command runs.

It contains zero logic of its own — it calls the same `formatChangedSources`
that `./singularity build` calls, so the repo's format policy cannot have two
implementations that disagree.
