# normalize-generated

`./singularity normalize-generated` — repairs generated files that a merge
driver resolved cheaply during a merge or rebase, by re-deriving them from the
merged sources and amending the head commit.

The merge drivers exist so a generated file never produces a conflict a human
has to resolve; the cost is that the resolved content is a guess, correct only
until the merged sources disagree with it. This command is the other half of
that bargain — the pass that turns the guess back into something derived.

It contains no logic of its own. `normalizeGeneratedArtifacts`
(`plugins/git-artifacts/cli`) is the implementation, shared with `push`, which
runs the same repair around its own rebase; the checker side of the same
contract is `generated-artifacts-normalized`.

Its normal invoker is the `post-rewrite` git hook, which fires after *every*
rebase and amend — so the interesting property is that it is marker-gated and
therefore a no-op when the merge touched no generated file. Running it by hand
is for one case: a check reported an un-normalized auto-resolve. It is
idempotent, so a second run costs nothing.
