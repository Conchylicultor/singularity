# places-api

A **stateless, typed Google Places API (New) client**. Every function takes the
`apiKey: string` as its first parameter and returns the neutral
`PlaceSuggestion` / `PlaceSnapshot` shapes from `core`. It calls
`https://places.googleapis.com/v1/...` and nothing else — no DB, no auth import,
no per-call state.

## Why separate from the broker

The parent plugin reads the key out of auth/central. This plugin is the opposite
half: the pure transport. Keeping it key-in / typed-value-out means it never
imports `@plugins/auth/*` and can be reused by any caller that can produce a key.

## The two calls

- `autocomplete(apiKey, input, sessionToken)` →
  `POST /v1/places:autocomplete`, body `{ input, sessionToken }`. A field mask is
  optional on this call. Rows without a `placePrediction` (Google's
  "query predictions") are skipped — there is no place to resolve behind them.
- `placeDetails(apiKey, placeId, sessionToken)` → `GET /v1/places/{placeId}`
  with `X-Goog-FieldMask` (**required** — omitting it is an error) and the
  session token as a query param.

**Session tokens**: mint one per search-to-selection round and pass it to both
calls, so Google bills the pair as a single autocomplete session.

## The field mask is a cost decision

`PLACE_DETAILS_FIELD_MASK` is one exported constant with the tier table in its
comment. v1 requests Essentials + Pro fields only, and deliberately omits the
Enterprise-tier ones (`rating`, `userRatingCount`, `regularOpeningHours`,
`internationalPhoneNumber`, `editorialSummary`) that roughly double the per-call
price. Adding one later is a one-line change with a known bill attached.

## Failure

Non-2xx throws `PlacesApiError` carrying Google's own message and `error.status`
(`REQUEST_DENIED`, "API not enabled", "billing not enabled"). A mapped
`PlaceSnapshot` is validated against its schema, so a response missing a name or
an address throws rather than producing a card with blanks. An empty suggestion
array only ever means Google found nothing.

There is no retry ladder (unlike gmail-api's `gmailRequest`): both calls sit on a
human's keystroke inside an autocomplete session, where a silent 30-second
backoff is worse than a visible failure.

## Plain `fetch`, on purpose

`@plugins/infra/plugins/safe-fetch` guards URLs a **user** supplied (SSRF).
`places.googleapis.com` is a fixed host written into this code, so plain `fetch`
is correct here — do not "fix" it later.
