# song-videos

"Which YouTube videos are this song?" — asked without naming who answers.
Design: `research/2026-10-07-apps-sonata-ug-alignment-video.md` (Part 2).

```ts
// server, in a supervised job's run body (a source may run yt-dlp):
const { candidates, sources, refused } = await findSongVideos({ artist, title }, exec, { log });
// candidates: RankedCandidate[] — best first, each with `match` and `reasons`

// a source (any plugin):
contributions: [SongVideos.Source({ id: "my-source", find: async (query, exec, { log }) =>
  ({ kind: "answered", videos: [...] }) /* or { kind: "unavailable", reason } */ })]
```

- **Sources.** `youtube-search` (this plugin's child: YouTube's first ten
  results for "<artist> <title>") and `hooktheory` (`apps/chord/song-index`:
  videos TheoryTab transcribers synced the song to, `human-synced`; only where
  the Chord index is loaded). `unavailable` is a state, never an empty list.
  A source that throws is reported in `sources` (`failed`) and the others
  still count; all failing throws `SongVideoSourcesFailedError`.
- **Merge** (`mergeSourceAnswers`, core): one candidate per video, each source
  and its position kept.
- **Embeddability.** Every candidate is asked over oEmbed (`checkOembed`, 6 in
  flight): `gone` / `not-embeddable` are dropped into `refused`, no answer is
  kept, and a 200 names an untitled candidate (a Hooktheory video has only its
  id). Before ranking, so a title can count.
- **Rank** (`rankCandidates`, core, pure): additive terms in `RANK_WEIGHTS` —
  title/artist token-set share, extra words, art track ("Provided to YouTube
  by", or a "- Topic" channel) > Official Audio > Official Video, the artist's
  own channel, `VERSION_TERMS` (live, cover, remix, …) unless the song's name
  has the term, a duration > 25 % off the median, human-synced, views, source
  position. `normalizeSongKey` folds case, accents, apostrophes,
  parentheticals, "feat." and a leading "The".

Tests: `core/internal/*.test.ts` (the ranking on a real results page included),
`server/internal/find.test.ts` (fake sources and oEmbed). The live search:
`./singularity run plugins/integrations/plugins/youtube/plugins/song-videos/scripts/search.ts "Oasis" "Wonderwall"`.

## Plugin reference

- Description: Which YouTube videos are this song? The SongVideos.Source contribution (a source's find(query, exec) → answered videos | unavailable) and findSongVideos(query, exec): every source asked at once, their answers merged per video, the ones oEmbed says will not play in an embed dropped (and untitled ones named from oEmbed), the rest ranked towards the studio recording. Names no source.
