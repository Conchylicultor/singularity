# edit-mode

Sub-plugin of `reorder`. Owns the user-facing edit-mode UI:

- An "Edit layout" switch row in the action bar's view-options (gear) popover
  (`ActionBar.ViewOption`) that toggles edit mode globally. It is
  `excludeFromReorder`, so it stays clickable while every other item in edit
  mode is a drag target.
- A registered Escape shortcut that exits edit mode.

This plugin only depends on `@plugins/primitives/plugins/edit-mode-signal/web` (for `setEditMode`/`useEditMode`) and `@plugins/shell/plugins/action-bar/web` (for the view-options slot). It is intentionally separate from the reorder primitive to avoid a cyclic import: shell's `slots.ts` wraps its slots with `Reorder.area`, so reorder cannot itself contribute to shell's slots.
