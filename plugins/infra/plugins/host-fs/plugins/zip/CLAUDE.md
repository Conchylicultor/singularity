# zip

Zip as a host-fs archive format (see the parent's *Archives browse like
folders*). A native reader — no npm dependency — of the zip central directory:

- The end record is searched in the last 64 KiB + 22 bytes; a saturated count,
  size or offset follows the zip64 locator to the zip64 end record, and a
  member's saturated sizes / offset come from its zip64 extra field.
- Names: the Info-ZIP Unicode Path field (0x7075) when its CRC matches the raw
  name; else UTF-8 when flagged (bit 11) **or** when the bytes are valid UTF-8
  (macOS's Archive Utility writes UTF-8 without the flag); else CP437.
- mtime: the extended-timestamp field (0x5455) when present, else the DOS
  date/time (local time).
- A name ending in `/` or Unix mode `S_IFDIR` is a directory; Unix `S_IFLNK`
  is `other` (never followed).
- Bytes: stored (0) → a `Blob` slice of the zip; deflated (8) → an inflating
  stream. Encrypted members are `encrypted`; any other method
  `unsupported-method`. Indexing reads only the table of contents.
