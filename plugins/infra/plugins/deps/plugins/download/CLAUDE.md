# download

The `download` installer kind of `infra/deps` — see the parent's
[`CLAUDE.md`](../../CLAUDE.md) for the engine.

```ts
// plugins/<feature>/deps/index.ts
export const dataset = defineDep({
  id: "my-dataset", owner: "…", description: "…", sizeHint: "≈20 MB",
  source: download({
    files: [{ name: "data.csv.gz", url: "https://…", sha256: "<64 hex>" }],
    // optional: post-process in env/, leaving exactly `outputs`
    derive: { version: "1", outputs: ["data.bin"], run: async (ctx) => { … } },
  }),
  updates: { none: "<why it is frozen>" },
});

// after ensureDep / readyNow:
const path = downloadedFile(ready, "data.csv.gz"); // throws on an undeclared name
```

- Pins are the identity: moving a url or sha256 (or bumping `derive.version`)
  is a new install beside the old one, never an overwrite.
- A sha256 mismatch throws; the engine records `failed.json` and the name is
  never populated with the wrong bytes.
- No updater of its own, so a declaration must say `updates: { none }`.
