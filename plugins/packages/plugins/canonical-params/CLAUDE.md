# canonical-params

One spelling per live-resource params tuple. `canonicalParams(params, optional)`
drops an `undefined` param, and a `""` for a name in `optional` (a `liveValue`'s
`"scopeId?"`), returning `params` itself when nothing is dropped.

It is the rule BOTH ends of the live-state wire apply — the browser
(`live-state`'s `useResource` / `useResourceAcks` / `hydrateResource`,
`optimistic-mutation`, `network/live`'s `preloadParams`) and the server
(`resource-runtime`, on every incoming frame, HTTP read, `notify` and cascade
tuple). The runtime echoes the canonical tuple in every frame it sends, so a
client that canonicalized differently would match none of them; one copy is
what keeps the two from drifting. A leaf with no imports, because
`resource-runtime` may import only leaves.
