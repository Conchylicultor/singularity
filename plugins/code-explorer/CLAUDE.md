# code-explorer

The worktree code reads behind `/api/code/:worktree/*` — a file's content, a
diff, an image, a push's or a commit's files — addressed by attempt id or the
reserved `main` / `self` sentinels. Server only: the browsing UI it used to ship
(the Explorer sidebar entry, the `FileTree` and the conversation's Files pane) is
now the file explorer app's `<FileBrowser/>` (`apps/file-explorer/browser`),
embedded by `conversations/conversation-view/explorer` and
`plugin-meta/plugin-view/file-tree`. The contracts live in `code-api`, the
commit-diff pane in `commit-detail`, fuzzy path resolution in `file-resolve`.
