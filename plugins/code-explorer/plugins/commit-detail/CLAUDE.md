# commit-detail

The one commit-diff pane, parameterized by worktree: any surface that can name a
`(worktree, sha)` pair pushes it — a conversation's commits graph, a commit-sha
chip in agent prose. Lives under `code-explorer` because it is the viewer half of
the `/api/code/:worktree/*` contracts; consumers open it the way `AttemptChip`
opens `attemptPane`.

**The worktree is a pane param, never an ancestor lookup.** Its predecessor
(`commits-graph`'s `convCommitDiffPane`) read the worktree off an ancestor
`conversationPane` and so rendered `null` anywhere without a conversation in
scope. `commit/:worktree/:sha` (the shape `code/:worktree` already uses) is read
from the body's own `useParams()`; keep it that way — a conversation lookup here
re-breaks every conversation-less surface.

**`useCommitInfo` is four-armed**: `loading | found | not-found | error`.
`not-found` (the server's determinate `Resolvable` non-value, a 200) and `error`
(we could not ask) must not collapse — only `not-found` suppresses the diff body.
`staleTime: Infinity`, since commit metadata is immutable.
